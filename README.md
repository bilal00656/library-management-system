# Library Management System

A basic full-stack architecture for managing library operations.

## Project Components

- Admin Frontend
- User Frontend
- Backend
- API
- Database

## Admin Panel

- Manage books
- Manage users
- Manage borrowing records

## User Panel

- Browse books
- Search books
- Check book availability
- Request books

## Project Status

This project currently contains the basic system architecture and project structure.
A working application is not required for this assignment.
